# HandGesture Vision

Real-time hand gesture recognition using:

- Python
- OpenCV
- MediaPipe
- PySide6

## Features

- Real-time webcam processing
- Hand landmark detection
- Gesture recognition
- Confidence score
- FPS monitoring
- Left/right hand detection
- Gesture history
- Screenshot capture
- Modern desktop UI

## Supported gestures

1. Open Palm
2. Fist
3. Thumbs Up
4. Thumbs Down
5. Victory
6. Pointing
7. I Love You
8. Three
9. Four
